# TTD-Piligrims-Analysis
Interactive Power BI dashboard analyzing TTD pilgrim traffic trends, weather impact, rolling averages, and operational crowd insights using real-world analytics techniques.
🛕 TTD Pilgrim Analytics Dashboard

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyze pilgrim crowd patterns, weather influence, and operational trends for TTD pilgrimage management.

📌 Project Overview

This project focuses on analyzing pilgrim traffic data to identify:

Crowd behavior patterns
Weekend vs weekday variations
Seasonal trends
Weather impact on pilgrim turnout
Rolling average growth trends
Operational insights for crowd management

The dashboard was designed as a real-world operational analytics solution to support data-driven decision making.

📊 Dataset Features

The dataset contains:

Date
Pilgrims Count
Weekday/Weekend Indicator
Humidity
Highest Temperature
Lowest Temperature
7-Day Rolling Average
📈 Key Dashboard Features
Crowd Trend Analysis
Daily pilgrim movement trends
Long-term growth visualization
Weather Impact Analysis
Temperature vs pilgrim traffic
Humidity analysis
Rolling Average Analysis
7-day moving average tracking
Trend stabilization insights
Operational Insights
Peak crowd identification
Weekend traffic analysis
Special-day trend monitoring

📌 Key Insights
Weekend pilgrim traffic was significantly higher than weekdays
Rolling averages revealed long-term upward trends
Moderate weather conditions attracted higher pilgrim turnout
Special days created noticeable traffic surges
